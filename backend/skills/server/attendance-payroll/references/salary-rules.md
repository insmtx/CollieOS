# 工资规则与字段

## 工资组成

系统应发工资 = 岗位工资 + 调整后绩效工资 + 工龄工资 + 职称工资 + 施工补贴 + 话费补贴 + 计入应发的高温补贴 + 交通补贴 + 加班费。

历史工资表字段映射：

- `基本工资` = 岗位工资；
- `绩效工资` = 绩效工资标准。若单元格是 `ROUND(2700/21.75*出勤,2)` 或 `2700-2700/21.75*事假`，基准取公式中的 2700，不得用已折算后的金额再扣一次；
- `工龄工资` = 工龄工资；
- `施工补贴`：优先保留并解析单元格公式（`工作天数×日标准` 或 `天数1×标准1+天数2×标准2`）；无公式的单项目月金额才按历史工作天数还原日标准；字面 0 就是 0；
- `交通补贴` = 交通补贴；
- `1-3月话补`、`4-6月话补`、`7-9月话补`、`10-12月话补`、`话费补贴` = 话费补贴基准及适用期候选；
- `降温费`、`高温补贴` = 高温补贴候选；
- `双休日加班`下的“标准/个数/金额”，以及单列`双休日加班`/`双休日加班金额` = 加班字段组；是否计加班费只看金额列是否大于 0，标准列有公式但金额为 0 视为一口价；
- `应发工资` = 历史人工应发工资，仅用于同月对比。

“工资标准”不是必须存在的字面字段。只要能够从上述业务字段中识别出岗位工资（基本工资）或其他固定工资分项，就应建立部分工资基准，不得以缺少“工资标准”列阻塞核算。

## 固定规则

| 项目 | 规则 |
|---|---|
| 应出勤 | 基础工作日 − 不扣薪休息工作日 − 调出/调入/走。周末和法定假已从基础工作日去掉，不得再减。调走、产假/陪产假（含备注「产30」）只按在本表出勤期间要求应出勤，缺口不得一刀切成事假 |
| 事假 | 缺口 − 旷工 − 病假；缺口 = max(应出勤 − 实际出勤, 0)。不数「事」格。≤7：岗位和绩效都扣标准/21.75×天数；>7：仍扣岗位、绩效为 0；≥应出勤：停发全部。扣后岗位、绩效 `ROUND(...,2)` |
| 病假 | 只认「病」/病假工作日，且不超过缺口。先于事假占用缺口。≤15 只扣绩效；>15 停发绩效、岗位不因病假扣 |
| 旷工 | 只认「旷」符号或旷工工作日。≥1 停绩效；累计≥5 或连续工作日≥3 停发全部 |
| 出勤对账 | 印刷「实际出勤」必须等于该行出勤符号（8/√/加班，不含换）个数；不一致列入复核，工资仍按印刷实际出勤 |
| 一口价加班 | 历史加班金额为空或 0 时不计算加班费，也不反推加班标准。标准列的日费率公式不是发放依据 |
| 通用加班日标准 | 仅对历史计过加班费的人员：ROUND(岗位工资 / 21.75, 0) × 2 |
| 基础工作日 | 按核算月份动态计算：当月天数 − 周六日天数（调休上班日除外）− 不与周末重复的法定节假日天数 |
| 加班天数 | min(max(实际出勤 − 基础工作日, 0), 当月周末自然周数量) |
| 施工补贴 | 优先用历史公式；单项目为当月实际出勤 × 日标准；跨项目为各项目出勤 × 对应日标准之和。无公式时单项目才用月金额÷历史工作天数；跨项目可引用同项目单标准同事。显式 0 不补同事标准 |
| 话费补贴 | 仅季度末月计入一次；同季度此前月份已发放则不重复，优先季度列，缺失时参考最近历史金额 |
| 高温补贴 | 默认 6—9 月；是否进入应发由基准字段决定 |
| 超计划出勤 | 记应休未休，不增加当月加班费 |

## 缺失字段处理

- 单个人员缺少岗位工资、绩效、补贴或加班字段时，只标记对应分项缺失，其他已确认分项继续计算；
- 整个月份缺少基础工作日或计划加班上限时，只停止加班费计算，工资其他分项继续计算；
- 只有考勤完全无法识别、考勤月份冲突或没有任何可识别考勤人员时，才阻塞整批核算。

## 对比

与本次提交且能唯一匹配的历史人工工资记录对比，不要求历史表与核算月份相同。金额容差为 0.01 元，天数容差为 0；输出总额差异和分项差异。系统生成的「工资核算明细 / 工资基准 / 考勤汇总 / 历史工资对比 / 人工复核事项」工作簿不是历史人工工资表，不得用于建立基准或对比。

## 禁止自动推断

病假超过 6 个月/医疗期生活费、入离职按天折算、调休余额、工龄晋档和正式高温政策未确认前不得计算。跨项目施工补贴在公式或同事日标准可确定时必须计算，不得整项打 0。
